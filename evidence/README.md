# Evidence folder

Store proof of your own lab observations here.

## Suggested contents
- `screenshots/` — screenshots showing the VM address, Mininet prompt, Snort running, alert log, and iptables rule.
- `logs/` — sanitized Snort alert excerpts and sanitized firewall output.
- `pcap/` — keep packet captures local by default; include one only if you are authorized to share it and have checked it for sensitive content.

## Evidence guidelines
- Use descriptive names such as `01-mininet-started.png` or `04-forward-rule-verified.png`.
- Capture your own screen; do not present worksheet examples as if they were your results.
- Hide credentials, tokens, personal details, and sensitive network information.
- Do not commit malware samples. Publicly share only sanitized evidence you are permitted to publish.
- This folder starts with a README; add evidence as you complete the practical.
