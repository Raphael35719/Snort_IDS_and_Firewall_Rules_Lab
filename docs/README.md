# Docs folder

This folder contains the written workflow and results for the Snort and firewall practical.

- Follow `LAB_WORKFLOW.md` in order.
- Use `RESULTS.md` to record your actual observations and answer the worksheet questions in your own words.
- Note differences between your environment and the worksheet.
- Do not invent outputs, timestamps, alert counts, or successful results.

The workflow is based on the uploaded “Lab - Snort and Firewall Rules” PDF.
